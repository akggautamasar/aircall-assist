## AirCall Assist ephemeral relay\n\nThis relay keeps only live WebSocket connections in memory.\n\n- No accounts.\n- No database.\n- No chat history.\n- No offline queue.\n- Messages are forwarded only while both devices are connected.\n- Use HTTPS/WSS in deployment.\n\nThe Android client sends hello, pair, and message events.\n\nThis is an MVP transport. Production hardening should add cryptographic session authentication and payload encryption before public release.\n
